## What is this

Vector is a synthetic-data demo of [SynthSec's](#author) lead intelligence methodology: it scores every lead 0-100 on conversion probability, flags the single most explanatory signal, and tiers leads (hot / warm / cold / unqualified) — combining behavioral engagement with a firmographic reality check that engagement alone can't provide.

This is a portfolio piece, not a client deliverable. All data is synthetic and clearly labeled as such.

## The problem

Sales teams often work leads in the order they arrived, not the order they matter. Engagement alone (email opens, clicks) doesn't tell you whether a lead can actually buy — a small company with no budget can click every email and still never convert, while a quiet enterprise lead with real intent gets deprioritized for lack of activity.

## What it does

```
synthetic lead + engagement-event CSVs
        │
        ▼
  pandas cleaning                → validate firmographics, reconcile events to valid leads
        │
        ▼
  feature engineering            → engagement counts/velocity + firmographic features, joined per lead
        │
        ▼
  K-Means segmentation           → hot / warm / cold / unqualified (unsupervised + business override)
        │
        ▼
  conversion classifier          → RandomForestClassifier predicts conversion probability (supervised)
        │
        ▼
  recommended actions            → plain-English next step + urgency, per lead
        │
        ▼
  Streamlit dashboard            → deployed on Hugging Face Spaces
```

## Key concepts

| Concept | 
|---|---|
| Two-table feature engineering | Behavioral features (from events) joined onto firmographic features (from leads) per entity |
| Weighted event scoring | A demo request signals more intent than an email open — event TYPE matters, not just count |
| Ordinal vs. one-hot encoding | `budget_tier` (has a real order) encoded ordinally; `source` (no order) encoded one-hot |
| Rank-based segment naming | Cluster names assigned by ranking centroids against each other, not fixed thresholds — a fix carried over proactively from Beacon |
| Business override | "Unqualified" overrides a high engagement score when budget/company size disqualify the lead — same pattern as Pulse's VIP floor |

## Dataset

100% synthetic, generated by `src/synthetic_data.py`. Each lead has a hidden "true intent" score that drives BOTH engagement-event frequency and conversion probability (via a logistic function combining intent, source quality, and budget quality) — one latent cause, two observable effects, closer to how real B2B lead behavior actually works.

## Results

Numbers from the bundled demo dataset (2,000 synthetic leads):

| Metric | Value |
|---|---|
| Leads scored | 2,000 |
| Segments found | 4 (hot, warm, cold, unqualified) |
| Silhouette score | 0.49 |
| Conversion classifier ROC-AUC | 0.75 |
| Conversion rate | ~14% |

The AUC here is honestly lower than Beacon's 0.96 — the synthetic conversion outcome has more irreducible randomness built into its generator (a probabilistic draw, not a hard threshold), which is closer to how noisy real B2B conversion actually is.
